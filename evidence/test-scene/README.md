# First playable study evidence

This is a limited prototype, not the complete adventure and not final visual acceptance. Baseline b5eb674 and first repair f9c57fb received independent reviews, with failures preserved. Review reports distinguish actual normal-input observations, emulation, captures and unverified listening/physical-phone results.

Original WebM recordings are retained locally in the named evidence directories and excluded from public git to avoid large repository payloads. Scripts, machine results, contact sheets and selected screenshots are versioned. The deployed docs directory contains no review assets.

Current sound is generated by original Web Audio synthesis and is labelled provisional. Atlas SFX retrieval/listening is still unresolved. No new Atlas spending followed the16-credit pilot.
