# Bellkeeper character candidate

CC0 source models by Quaternius, downloaded from the authors’ free Standard editions on 17 September 2026:

- Universal Base Characters: https://quaternius.com/packs/universalbasecharacters.html — Superhero_Male_FullBody (head/eyes/brows only at runtime), Hair_Long.
- Modular Character Outfits — Fantasy: https://quaternius.com/packs/modularcharacteroutfitsfantasy.html — Male_Peasant.
- Original license notices are adjacent. No paid source edition was purchased.

GLTF geometry, skinning, and base-colour textures were packed into GLB; unused normal/ORM images were omitted. Runtime modifications adjust head proportions, nose/jaw/eye regions, brows, hair length, materials and colours. Original scarf, turquoise clasp and bell accessory are code geometry. The character is bound to the outfit skeleton, with bind-space transfer from the CC0 Universal Animation Library clips in ../quaternius/.

Atlas R06 was a 2D visual direction reference, not a generated 3D asset. No Nintendo model, texture, animation or audio is included.
